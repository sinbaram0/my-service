# 비밀번호 재설정

로그인 화면의 **비밀번호를 잊으셨나요?** → 가입 이메일 입력 → **재설정 메일 받기** → 이메일 링크 열기 → 새 비밀번호 및 확인 입력 → 변경 후 다시 로그인 순서입니다.

Supabase Authentication → URL Configuration → Redirect URLs에 실제 사용하는 주소를 등록해야 합니다.

- 개발: `http://127.0.0.1:3000/reset-password`
- localhost로도 접속한다면: `http://localhost:3000/reset-password`
- 운영: 운영 사이트의 정확한 `/reset-password` 주소

허용 목록에 없으면 Supabase가 Site URL로 돌려보낼 수 있습니다. 메일 발송 한도에 도달했다면 반복 요청하지 말고 잠시 후 재시도합니다. 링크가 만료되었거나 이미 사용되었다면 새 메일을 요청합니다. 관리자의 비밀번호 직접 변경이나 사용자 테이블 수정은 필요하지 않습니다.

앱은 Supabase SDK의 `resetPasswordForEmail`과 `updateUser`를 사용합니다. 새 비밀번호는 컴포넌트 메모리에서 입력을 처리해 인증 서버에만 전송하고, 성공 시 입력을 지웁니다. 앱의 DB, URL, 파일 또는 로그에 비밀번호를 저장하지 않습니다. 이메일과 새 비밀번호를 실제로 입력하는 수동 검사는 사용자만 수행합니다.

변경 후 `signOut({ scope: "global" })`으로 세션 갱신 권한을 해제합니다. 이미 발급된 접근 토큰은 만료 전까지 유효할 수 있습니다. 재설정 메일 링크와 토큰은 대화나 저장소에 공유하지 마세요.
