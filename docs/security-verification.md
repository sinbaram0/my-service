# 로그인 및 사용자별 데이터 분리 점검

## 재검증 결과 (2026-11-09)

- 실제 연결 프로젝트의 DB 검사 재실행: 두 계정 간 조회·수정·삭제 차단, 소유자 위조 및 연결 테이블 변경 차단, 비로그인 접근 차단, 신규 사용자 번호 발급 모두 통과. 테스트 행은 트랜잭션에서 되돌렸습니다. 시퀀스 번호는 일부 소비될 수 있습니다.
- 인증·비밀번호 재설정 모의 테스트 8개, 린트, TypeScript, 프로덕션 빌드, 변경 공백 검사 통과.
- 현재 프로젝트 Git 저장 후보 34개와 origin/main 이후 기존 커밋 4개의 전체 트리에서 텍스트 파일/버전 142개를 검사했습니다. 알려진 키·토큰·비밀번호 하드코딩 패턴 및 현재 환경변수의 키 값과 일치하는 내용은 발견되지 않았습니다. 비밀정보 값은 출력하거나 기록하지 않았습니다. 이 검사는 모든 형태의 비밀정보 부재를 보증하지 않습니다.
- `.env.local`은 무시 대상이며 추적 중인 환경 파일은 없습니다. 공개 키는 앱 실행 시 브라우저에 전달되지만 Git 코드에 하드코딩되어 있지 않습니다.
- 실제 화면에서 A/B 가입·로그인·전환 및 비로그인 리디렉션은 사용자 완료 확인이 없어 미검증입니다. 모의 검사와 DB 검사 결과만으로 전체 통과로 판정하지 않습니다.
- Supabase 보안 점검의 유출 비밀번호 차단 비활성화 경고가 여전히 남아 있습니다. 설정 검토가 필요합니다.
- 기존 업로드 대기 커밋에는 `PRJ_my-service`와 `Project_PRD` 변경도 포함됩니다. 현재 상태에서 푸시하면 함께 업로드됩니다.
- 점검 결과는 로컬 파일에 저장했습니다. 실제 화면 미검증 및 보안 경고가 남아 있어 조건부로 요청된 커밋·푸시는 수행하지 않았습니다. 데이터 삭제나 접근 권한 확대는 하지 않았습니다.

아래 내용은 이전 점검 기록입니다.

## 자동 확인 결과

- 원격 DB의 두 사용자 간 조회 차단, 타인 행 수정·삭제 차단, 소유자 위조 저장·변경 차단: 통과.
- 비로그인 DB 접근 및 사용자 연결 테이블 변조 차단: 통과.
- 신규 계정의 숫자 사용자 번호 발급: 통과. 테스트용 변경은 트랜잭션에서 되돌렸습니다. 시퀀스 번호는 재사용하지 않으므로 테스트 이후 번호에 빈자리가 생길 수 있습니다.
- 비로그인 todos의 로그인 이동과 인증 서버 오류 시 비공개 화면 표시 차단: 모의 컴포넌트 검사 통과. 실제 브라우저 검사와는 구분합니다.
- 비밀번호 재설정 및 인증 관련 모의 검사: 8개 통과.
- `npm run build`, `npm run lint`, `git diff --check`: 통과.

## 저장 대상과 비밀정보

- 현재 프로젝트의 Git 추적·추가 후보 파일 및 origin/main 대비 업로드 대기 중인 기존 커밋 4개의 전체 파일을 패턴 검사했습니다. 텍스트 파일/버전 72개에서 API 키, JWT, 개인 키, 자격증명 포함 URL, 비밀번호·키 하드코딩 탐지 항목은 없었습니다.
- 현재 설정된 공개 API 키가 코드에 그대로 포함되는지도 대조했습니다. 발견되지 않았습니다. 키 값은 출력하거나 보고서에 저장하지 않았습니다.
- `.env.local`은 Git에서 제외되며 추적되지 않습니다. 앱의 키 유형은 공개용 publishable입니다. 이 키는 앱 동작 중 브라우저에 전달되며 데이터 보호는 RLS가 담당합니다. 빌드 산출물 `.next`는 저장 대상에서 제외됩니다.
- `.codex` 로컬 작업 폴더 및 `debug.log`도 Git에서 제외했습니다. ESLint는 `.codex`의 보조 스냅샷을 검사하지 않습니다.
- 패턴 검사는 알려진 형태의 유출을 찾는 검사이며 모든 형태의 비밀정보 부재를 증명하지는 않습니다. 실제 사용자 비밀번호·세션 저장소·비밀번호 해시를 조회하지 않았습니다.

## 실제 화면 검사: 완료 확인 필요

| 단계 | 상태 |
|---|---|
| 1. A 가입/로그인 → 할 일 추가 → 새로고침 후 유지 | 사용자 확인 대기 |
| 2. A 로그아웃 → B 가입 | 미검증 |
| 3. B에서 A의 할 일이 보이지 않음 | 미검증 |
| 4. B 할 일 추가 → A로 다시 로그인 | 미검증 |
| 5. A에서 B의 할 일이 보이지 않음 | 미검증 |
| 6. 비로그인으로 /todos 접근 → /login 이동 | 실제 화면 미검증 |

각 단계 완료 확인 전에는 다음 단계로 진행하지 않습니다. 개발 화면은 `http://127.0.0.1:3000/login`입니다. 비밀번호와 재설정 링크를 대화에 공유하지 않습니다.

## 남은 확인 사항

- Supabase의 유출 비밀번호 차단 기능이 비활성화되어 있다는 보안 알림이 남아 있습니다. [설정 안내](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)
- 비밀번호 재설정의 실제 이메일 수신과 링크 사용, Redirect URLs 허용 설정은 미검증입니다.
- Git 저장소는 프로젝트 상위 디렉터리에 있으며 원격은 `github.com/sinbaram0/homepage.git`입니다. 기존 업로드 대기 커밋에는 다른 프로젝트 변경도 포함됩니다. 향후 푸시 전에 이 범위를 다시 확인해야 합니다.
- 전체 통과로 판정하지 않았습니다. 작업 파일은 로컬에 저장했으며 이번 점검에서는 스테이징·커밋·푸시하지 않았습니다.
